## Markdown Portfolio Section

```md
# Smart Manufacturing AI Operations Platform

![Smart Manufacturing AI Operations Platform - Command Center](https://raw.githubusercontent.com/prsworkswgg/smart_manu/codex/streamlit-portfolio-polish/assets/screenshots/desktop/01_command_center.png)

**Live demo:** https://smart-manu-portfolio-prsworkswgg.streamlit.app/  
**Source code:** https://github.com/prsworkswgg/smart_manu/tree/codex/streamlit-portfolio-polish  
**Role:** Full-stack Industrial AI / Machine Learning Engineering project  
**Tech stack:** C# .NET, FastAPI, Python, SQLite, scikit-learn, Streamlit, Plotly, pytest

Smart Manufacturing AI Operations Platform is an end-to-end industrial AI
portfolio demo for smart manufacturing operations. It connects synthetic data
acquisition, API ingestion, SQLite storage, data quality checks, ML workflow,
inference endpoints, and a Streamlit command-center dashboard.

The dashboard is designed as a decision surface, not only a chart page. The main
view focuses on four operational KPIs, metric trust badges, an action queue, and
a line risk map. Detailed analysis is moved into drill-down pages for data
collection, line monitoring, machine investigation, anomaly investigation, data
quality, model training, and reports.

Every metric is tagged with a trust label: Live, Replay, Derived, Model
unavailable, or Not checked. This makes the dashboard more honest because the
viewer can distinguish live-like demo data, replayed historical records,
calculated metrics, model-dependent values, and unchecked sources.

## What I Built

- C# .NET data acquisition service for synthetic machine and production events.
- FastAPI backend for ingestion, storage access, and inference endpoints.
- SQLite demo data layer for local and Streamlit Community Cloud deployment.
- Python data quality checks and ML workflow for failure risk, RUL, and anomaly detection.
- Streamlit operations command center with responsive desktop and mobile layouts.
- i18n audit tooling to keep Thai and English UI pages separate.
- Visual regression screenshots for desktop and mobile portfolio evidence.

## Important Boundary

This project uses synthetic manufacturing data only. It is not a real factory
deployment, not a factory-certified predictive maintenance model, and not a
closed-loop production control system.
```
